# AI Grader - Full Stack Application

A full-stack MERN application for AI-powered evaluation of handwritten answer sheets using OCR and the Gemini API.

## Features

- **Teacher Portal**: Create exams, upload answer keys, and review student submissions
- **Student Portal**: Submit answer sheets and receive AI-powered grading and feedback
- **OCR Processing**: Extract text from PDF answer sheets using Python OCR
- **AI Grading**: Automatic grading using Google's Gemini API
- **Real-time Updates**: Instant grading results and feedback

## Tech Stack

### Frontend
- React 18 with TypeScript
- React Router for navigation
- Tailwind CSS for styling
- Context API for state management
- Lucide React for icons

### Backend
- Node.js with Express
- MongoDB with Mongoose
- Multer for file uploads
- Python OCR script for text extraction

### AI & OCR
- Google Gemini API for grading
- Python with pytesseract for OCR
- pdf2image for PDF processing

## Setup Instructions

### Prerequisites

1. **Node.js** (v16 or higher)
2. **MongoDB** (local or cloud instance)
3. **Python 3** with pip
4. **Tesseract OCR** installed on your system

### Backend Setup

1. Navigate to the server directory:
```bash
cd server
```

2. Install Node.js dependencies:
```bash
npm install
```

3. Install Python dependencies:
```bash
cd scripts
pip install -r requirements.txt
cd ..
```

4. Create a `.env` file (copy from `.env.example`):
```bash
cp .env.example .env
```

5. Configure the `.env` file:
```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_gemini_api_key
```

**Important**:
- Get your MongoDB URI from [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) or use a local MongoDB instance
- Get your Gemini API key from [Google AI Studio](https://makersuite.google.com/app/apikey)

6. Start the backend server:
```bash
npm start
```

For development with auto-reload:
```bash
npm run dev
```

### Frontend Setup

1. From the project root, install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Installing Tesseract OCR

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install tesseract-ocr
```

**macOS:**
```bash
brew install tesseract
```

**Windows:**
Download and install from: https://github.com/UB-Mannheim/tesseract/wiki

## API Endpoints

### Authentication
- `POST /api/auth/teacher/register` - Register a new teacher
- `POST /api/auth/teacher/login` - Teacher login
- `POST /api/auth/student/register` - Register a new student
- `POST /api/auth/student/login` - Student login

### Exams
- `POST /api/exams/create` - Create a new exam (with answer key PDF)
- `POST /api/exams/teacher-exams` - Get all exams for a teacher
- `POST /api/exams/student-exams` - Get available exams for a student
- `GET /api/exams/:examId` - Get exam details
- `DELETE /api/exams/:examId` - Delete an exam

### Submissions
- `POST /api/submissions/submit` - Submit answer sheet (with PDF)
- `POST /api/submissions/student-submissions` - Get student's submissions
- `POST /api/submissions/exam-submissions` - Get all submissions for an exam
- `GET /api/submissions/:submissionId` - Get submission details

## Database Schemas

### User Schema
```javascript
{
  name: String,
  email: String (unique),
  password: String (hashed),
  role: 'teacher' | 'student',
  sections: [String]
}
```

### Exam Schema
```javascript
{
  title: String,
  teacherId: ObjectId (ref: User),
  answerKeyText: String,
  section: String,
  maxMarks: Number,
  createdAt: Date
}
```

### Submission Schema
```javascript
{
  studentId: ObjectId (ref: User),
  examId: ObjectId (ref: Exam),
  studentAnswersText: String,
  status: 'pending' | 'graded',
  totalMarks: Number,
  feedback: String,
  gradedAt: Date,
  submittedAt: Date
}
```

## Usage Flow

### For Teachers:
1. Register/Login to the teacher portal
2. Create a new exam by uploading an answer key PDF
3. View all created exams
4. Click on an exam to see student submissions
5. Review grades and feedback generated by AI

### For Students:
1. Register/Login to the student portal
2. View available exams for your section
3. Submit your answer sheet as a PDF
4. View grading results and detailed feedback

## How It Works

1. **Exam Creation**: Teacher uploads answer key PDF → OCR extracts text → Stored in database
2. **Answer Submission**: Student uploads answer sheet PDF → OCR extracts text → Sent to Gemini API
3. **AI Grading**: Gemini compares student answer with answer key → Returns marks and feedback
4. **Results Display**: Student and teacher can view grades and detailed feedback

## Troubleshooting

### OCR Issues
- Ensure Tesseract is properly installed and in your PATH
- Check that pdf2image can find poppler (may need separate installation on Windows)

### MongoDB Connection
- Verify your MongoDB URI is correct
- Check network access if using MongoDB Atlas
- Ensure your IP is whitelisted in MongoDB Atlas

### Gemini API
- Verify your API key is valid
- Check API quota limits
- Ensure proper network connectivity

## Production Deployment

1. Build the frontend:
```bash
npm run build
```

2. Configure production environment variables
3. Deploy backend and frontend separately or together
4. Ensure MongoDB and OCR dependencies are available on the server
